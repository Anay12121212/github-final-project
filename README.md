# GitHub Final Project

## Project Description
This project demonstrates the use of Git and GitHub for repository management, version control, collaboration, and Bash scripting.

## Features
- Public GitHub repository
- Project documentation
- Open-source license
- Code of conduct
- Contribution guidelines
- Simple interest calculator written in Bash

## Installation
Clone the repository using:

```bash
git clone https://github.com/Anay12121212/github-final-project.git
```

Replace `Anay12121212` with your actual GitHub username.

## Usage
Run the simple interest calculator using Bash:

```bash
bash simple-interest.sh
```
